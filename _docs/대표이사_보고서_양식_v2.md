## 1. 제정 배경

대표이사 지시(2026-10-03): "대표이사 보고서는 회사 양식을 참조해서 공식적 보고서로 포맷을 적용. 밝은 톤으로 체계적 위계와 이전한 일, 앞으로 할 일, 무엇이 문제인지 어떻게 해결했는지, 그리고 앞으로의 계획 등등 참고되는 사례조사를 꼼꼼하게 해서 대표이사 보고서 양식을 새로 만들어서 다시 보고해."

이에 따라 한국 공식 업무보고서 관행과 국제 CEO/Board Report 표준을 조사해 본 양식을 제정한다.

## 2. 조사 근거

### 2.1. 한국 공식 업무보고서 관행

| 출처 | 확인한 원칙 |
|------|-------------|
| 기업마당 기업업무용 서식 | 주간업무실적·계획, 달성률, 미결사항, 건의사항 구조 |
| 비즈폼 표준 주간 업무보고서 | 금주실적 → 차주계획 → 요청사항 3단 구조, ISO 문서 표준화 |
| 폼팩 주간보고서 양식 | 보고자·부서·수신·결재란 필수, A4 1페이지 유지 |
| 팬루안 업무보고서 작성법 | 두괄식(결론 먼저), 수치 사용, 문제는 원인+영향까지 |
| 브런치 보고서 쓰는 법 | 결과-근거-향후계획 흐름, 개조식(□○-) 위계 |
| 공유사무소 보고 스킬 | 문제만 던지지 말고 옵션 2개 이상 제시 |

### 2.2. 국제 CEO/Board Report 표준

| 출처 | 확인한 원칙 |
|------|-------------|
| Business-in-a-Box Executive Report | Executive Summary는 독립 문서로 읽혀야 함, 1~2페이지 |
| EC-UNDP CEO Report to Board | Executive Summary → Financial → Operational → Strategic → Risk → HR → Governance → Outlook |
| Diligent Executive Summary | 배경 → 목표 → 핵심 발견 → 권고 → 결론 5요소 |
| BoardPro CEO Report Template | RAG(Red/Amber/Green) 상태 표시 일관 사용, 핵심 2~4페이지 + 부록 |
| Ivey Business Journal | 헤딩·색상·화살표·차트 활용, 사실·증거 기반, 12pt 이상 산세리프 |
| Diligent Board Reporting | 표준 템플릿 사용, 명확성·간결성, 데이터 시각화 |

### 2.3. 도출한 설계 원칙

1. **밝은 톤** — 흰 바탕 + 네이비(#1a3a6b)/블루(#1976d2) 포인트. 어두운 배경 금지.
2. **체계적 위계** — I. 대분류 → 1. 중분류 → ■ 소제목. 목차도 계층형.
3. **공식 문서 격식** — 문서번호, 보고일, 보고자, 수신, 분류, 결재란(작성/검토/승인).
4. **두괄식** — 보고 요약(Executive Summary)을 맨 앞에.
5. **문제→해결 명시** — 문제 상황과 해결 조치를 박스로 분리.
6. **RAG 상태 표시** — 완료/진행/대기/위험을 색상 배지로 일관 표기.
7. **수치 기반** — "열심히 했다" 대신 "E2E 8/8 통과".
8. **승인 요청 분리** — 대표 결정이 필요한 항목을 별도 박스로.

## 3. 문서 구조 (9장 고정)

| 장 | 제목 | 내용 |
|----|------|------|
| I | 보고 요약 (Executive Summary) | 성과·조직운영·문제·결정필요 4항목 |
| II | 이번 기간 완료한 일 | 제품 개발 / 사업 기획 / 기술 인프라 |
| III | **조직 구성원별 업무 배치와 실적** | 조직 구성 + 부서별 실적(누가 무엇을 했는가) + 배치 방식 + 자동 운영 체계 |
| IV | 문제와 해결 | 문제 상황 → 해결 조치 (박스 쌍) |
| V | 현재 상태 | 핵심 지표(KPI) + 진행률 + 인프라 + 조직 운영 현황 |
| VI | 앞으로 할 일 — 누가 무엇을 할 것인가 | 즉시(1일) / 단기(1주) / 중기(1개월), **담당·의존 열 필수** |
| VII | 리스크 관리 | 확률·영향·대응·**담당** |
| VIII | 대표 승인 요청 | 승인 항목 표(비용·담당·효과) + 판단 요청 |
| IX | 결론 | 이번 기간 성과 + 조직 운영 평가 + 남은 병목 |

### III장 필수 4절 (2026-10-03 대표 지시로 추가)

대표 지시: "누가 무엇을 했고 앞으로 무엇을 할지, 조직구성원에게 업무를 어떻게 배치해서 원활하게 업무를 진행했는지를 알고 싶어."

1. **조직 구성** — 부서 / 담당 / 역할 3열 표
2. **부서별 실적** — 부서마다 `info-box` 하나씩, **수치 포함** 실적 나열 (누가 무엇을 했는가)
3. **업무 배치 방식** — `solution-box`에 배치 원칙 (병렬 배치 / 자동화 우선 / 승인 게이트 집중 / 단일 장애점 제거 / 산출물 기반 검수)
4. **자동 운영 체계** — 크론 표 (주기 / 업무 / 담당)

### VI장 필수 (앞으로 할 일)

작업마다 **담당**과 **의존(선행 조건)**을 반드시 명시한다. "누가 무엇을 할 것인가"가 드러나야 한다.

## 6. 작성 규칙

1. **결론을 먼저 쓴다** — I장 요약만 읽어도 의사결정이 가능해야 한다.
2. **수치로 말한다** — "개선했다" 대신 "3.2MB → 16MB".
3. **문제는 원인과 영향까지** — 문제 상황 박스에 원인·영향을 함께 적는다.
4. **해결은 조치와 결과까지** — 해결 박스에 무엇을 했고 결과가 무엇인지 적는다.
5. **날짜는 시스템 시계로 확인** — `date` 명령 사용, 기억 속 연도 금지.
6. **출처는 끝에 모은다** — 조사 근거가 있으면 명시.
7. **승인 항목은 분리** — VIII장에 별도 박스, 비용·담당·효과를 함께 표기.
8. **누가 했는지 밝힌다** — 실적마다 담당 부서를 명시. III장에서 부서별로 나눠 적는다.
9. **앞으로의 일에도 담당을 붙인다** — VI장 작업마다 담당과 의존(선행 조건)을 적는다.
