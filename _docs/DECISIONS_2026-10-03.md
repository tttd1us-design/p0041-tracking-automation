## 결정 1 · 안티그래비티 브리지 — **가동 확정** ✅ 집행완료

**판단:** "안티그래비티는 GUI 전용이라 자동화 불가"라는 기존 결론은 **틀렸다.** 실측으로 CLI 접점을 찾았다.

- `language_server.exe agentapi` (문서화되지 않은 내부 API)
- 실동작 검증: 대화 생성 → 응답 수신 → 텍스트 추출 모두 성공
- 응답 품질 검증: 엑셀 아이템 리스크를 정확히 지적 (SI 전락 위험)

**집행:** `_tools/antigravity_bridge.py` + `10jo-antigravity` 스킬 생성. **추가비용 0원.**

**역할 배정:** 안티그래비티 = 제3자 검토·반박 전담. (Claude Code = 코드, 고문 = 문서, 수석 = 기획)

## 결정 2 · `hermes proxy` — **가동 확정** ⏳ 집행 중

**판단:** 이게 **"추가비용 없이 원활하게"의 실제 해답**이다.

- Nous Portal OAuth 구독을 **로컬 OpenAI 호환 API로 변환**
- OpenCode·aider·llm·sgpt 등 **API 키가 없어 놀고 있는 도구 전부**가 여기 붙는다
- 대표님 구독 범위 안이므로 **추가 과금 없음**

**집행:** `hermes proxy start` → 각 CLI에 `base_url=http://127.0.0.1:<port>/v1` 연결.

**효과:** 인증 0개로 놀던 OpenCode가 즉시 코딩 에이전트로 가동.

## 결정 4 · 로컬 LLM — **불가 확정** ❌

**판단:** 제안된 "Qwen 2.5-Coder 32B 로컬 구동"은 **이 PC에서 물리적으로 불가.**

- GPU: RTX 3060 Laptop **6GB VRAM**
- 32B 모델 양자화 시 필요: 18~20GB

**대안:** 로컬이 필요하면 7~8B 모델만 가능. 단 **Nous 무료 모델(1M 컨텍스트)이 더 우수**하므로 로컬 구축은 보류.
