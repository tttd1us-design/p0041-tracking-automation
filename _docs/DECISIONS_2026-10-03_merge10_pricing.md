## 결정 이유

### 1. 구독은 기술적으로 불가능 (모순 확인)

안티그래비티 검증:
> "전통적인 '자동 갱신형 구독'은 불가능합니다. 자동 결제를 위해서는 결제사가 발급한 '빌링키'를 사용자 계정과 매칭하여 보관할 DB가 필수적이기 때문입니다."

우리 제약(서버 없음 + 개인정보 수집 없음)과 정면 충돌. **구독을 고집하면 서버를 만들어야 하고, 그 순간 "파일이 브라우저 밖으로 나가지 않는다"는 핵심 약속이 무너진다.**

### 2. 오프라인 라이선스로 서버 없이 과금 가능

안티그래비티 검증:
> "Web Crypto API는 외부 라이브러리 없이도 ECDSA(P-256) 서명 검증을 네이티브로 지원합니다."
> "공개키는 공개되어도 무방합니다. 이 키로는 검증만 가능하고 서명 생성은 불가능합니다."

**서버 0원 + 라이선스 검증 가능.** 매출총이익률 97% 유지.

### 3. 우회 가능성은 인정한다 — 그러나 타깃이 방어한다

안티그래비티의 가장 중요한 지적:
> "해커는 암호화를 깰 필요가 없습니다. 개발자 도구를 열어 검증 로직 자체를 무력화하면 됩니다."
>
> **"감수할 만한 가치가 있는 경우: B2B(기업용) 솔루션인 경우 — 기업 고객은 법적 리스크와 컴플라이언스 문제 때문에 굳이 JS를 해킹해 사용하지 않습니다."**
>
> **"가치가 없는 경우: B2C 대상이거나 주 사용자가 개발자/학생인 경우 — 하루 만에 GitHub에 크랙이 올라옵니다."**

**판단: 타깃을 회사 경리·총무 담당자로 고정한다.** 이들은:
- 감사 대응이 필요한 직무 (크랙 쓸 이유가 없음)
- 3만 원을 개인 시간 들여 우회할 유인이 없음
- 오히려 "제대로 된 도구"를 원함

### 4. 가격 근거

- 크몽 엑셀 자동화 시세: 3만~25만 원 (일회성 외주)
- 우리 평생권 39,000원 = **크몽 최저가보다 저렴, 반복 사용 가능**
- 24시간 패스 2,900원 = "급할 때 커피 한 잔 값"

### 5. 시계 되돌리기 방어

localStorage에 마지막 실행 시각 저장 → 현재 시각이 그보다 과거면 라이선스 무효화.
완벽하지 않음(캐시 삭제 시 무력화)을 **인정**하되, 이 또한 정직한 사용자 방어선으로 충분.
