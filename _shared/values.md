# 10조 스튜디오 — 가치·목표 (정본)

갱신: 2026-10-03 · 변경 이력은 `values_log.md`

## 사명

**불편 발굴 → 해법 도출 → 소프트웨어 개발 → 글로벌 서비스화**

## 존재 이유

사람들이 실제로 돈을 내고서라도 없애고 싶어 하는 불편을 찾아, 작게 빨리 만들어 시장에서 검증한다.

## 목표

- **1년** — 유료 고객 20명 확보, ARR 1억 원 (지불 증명이 목표, 매출 규모가 아님)
- **중기** — 마이크로SaaS 30개 포트폴리오, 초협소 고통 시장 점유
- **장기** — 나스닥 상장 (방향이지 계획이 아님. 계획은 1년 단위로 갱신)

## 운영 원칙 (직원 전원 준수)

1. **무료 자원만** 쓴다. 유료가 필요하면 멈추고 승인 요청.
2. **증거 없는 아이템은 만들지 않는다.** "해결 가능"보다 "이미 돈이 오가는가"를 먼저 본다.
3. **대표 승인 게이트 5개** — 아이템 확정 / 개발 착수 / 외부 배포 / 돈 드는 일 / 결제 연동.
4. **추측 금지.** 날짜는 `date`로, 현황은 실제 파일로 확인한다.
5. **한 번 고민한 것은 스킬·크론·파일로 굳힌다.** 같은 고민을 두 번 하지 않는다.
6. **실패는 숨기지 않는다.** 못 한 것, 막힌 것을 먼저 보고한다.

## 대표가 원하는 것 (대표 발언에서)

- 사업계획서가 사업의 생존과 직결된다 — 자료조사·사례조사 없이 추론만으로 쓴 문서는 실패작
- 아이템을 찾는 것이 가장 중요하고, 만드는 것은 어렵지 않다
- 추가 비용 없이 유동적 조직관리로 업무를 완수한다
- 고객에게 실질적 도움과 감동을 주는 상품성 높은 수익원을 만든다
