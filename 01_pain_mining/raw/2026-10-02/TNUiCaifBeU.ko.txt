엑셀 작업할 때 이런 흐름 많이 해
보셨을 겁니다. 엑셀 파일을 열고
데이터 일부를 복사해서 채 GPT에
붙여 놓고 답변을 다시 엑셀에
옮깁니다.
매크로나 자동화 작업을 하려면
생각보다 손이 더 많이 갑니다.
요즘은 채 GPT가 엑셀 파일을 직접
만들어 주기도 하지만 그것도 완전히
편하지만은 않습니다. 파일을 생성하고
다운로드하고 정상적으로 실행되는지
확인하고 잘 안 되면 다시 업로드에서
수정 요청하고 그 과정을 반복해야
합니다. 진짜 손 가고 엄청
귀찮습니다.
특히 데이터가 많거나 엑셀 파일
자체가 무겁다면 채 GPT에서 아무리
돌려도 제대로 출력도 안 되고 자꾸
이상한 단번 나올 때가 허다합니다.
그래서 저는 아예 엑셀 에이전트를
만들어서 돌리기도 합니다. 그런데
엑셀 에이전트를 직접 만드는 것도
쉬운 일은 아니죠. 혹시 이런 상황
여러분에게도 해당되나요? 그렇다면
이번 업데이트가 반가울 거라고
생각합니다. 이번에 오픈 AI가
업데이트한 채 GPT4 엑셀 앤 구글
시트는이 흐름을 바꿉니다. 핵심은
단순합니다. AI가 채팅창 밖으로
나와서 엑셀 안으로 들어왔습니다.
크랩 일에 바로 쓰는 AI.
이번 기능은 엑셀이나 구글 시트
안에서 채 GPT를 사이드바 형태로
사용할 수 있는 구조입니다. 중요한
건 그냥 엑셀 옆에 채봇 하나가
붙었다는게 아닙니다. 그러니까
코파일럿 같은 구조가 아닙니다.
코파일럿은 정말 UI 흐름이 정말
구입니다. 왜 엔진은 그렇게 잘
만들어 놓고 쓸 수 없게 만들어
놨는지 너무 아깝습니다.
저는 빈 검색의 AI가 처음 붙었을
때부터 꾸준히 써 왔는데 아 진짜
UI 플로우랑 사용자 경험 좀 챙겨
주세요. 그런데 이번 채 GPT
방식은 다릅니다. 바로 엑셀이랑
실시간 연동되고 채 GPT 기능도 다
쓸 수 있습니다. 즉 채 GPT
외브앱 연동으로 실시간 엑셀
업데이트도 가능합니다. 바로 이거죠.
이렇게 만들어야 엑셀 안에서 AI를
쓰는 보람이 있습니다. 그리고이
흐름은 채 GPT만의 이야기도
아닙니다. 최근에 클로드도 엑셀
연동에 대한 대대적인 업데이트가
있었습니다. 기능은 비슷합니다.
그래서 만약 채 GPT는 무료 버전
위주로 쓰고 클로드 유료 버전을 쓰고
계신 분이라면 클로드 쪽 연동을 더
추천합니다. 그럼 실제로 무엇을 할
수 있느냐? 아직 세 기능이라 앞으로
더 발전하겠지만 현재 기준으로도 꽤
실용적입니다. 스프레드시트를 만들고
외브앱과 연동해서 실시간 데이터
업데이트하고 정리가 안 된로 데이터를
전 처리해 줍니다. 이것만 해줘도
엑셀 업무 시간이 꽤 줄어듭니다.
특히 중요한 건 멀티탭태 파일,
수식, 참조 관계, 가정이 들어간
파일까지 다룰 수 있다는 점입니다.
말만 들어도 편해 보이죠? 그런데
사실 편한 것만이 핵심은 아닙니다.
이게 중요한 이유는 엑셀은 단순한
표가 아니기 때문입니다. 직장인에게
엑셀은 업무의 중간 저장소입니다.
매출표, 비용표, 고객 목록, 설문
응답, 프로젝트 관리표, 운영 리포트
대부분의 업무가 어떤 형태로든
엑셀이나 시트에 들어갑니다. 그래서
AI가 엑셀 안으로 들어왔다는 건
단순히 엑셀 기능이 하나 늘어난게
아닙니다. AI가 우리가 실제로
일하는 파일 안으로 들어오기
시작했다는 뜻입니다. 그럼 이제
우리는 업무 과정마다 실시간으로 AI
다양한 적용이 가능하다는 말이죠.
예전 방식은 이랬습니다. 엑셀에서
데이터를 봅니다. 필요한 부분을
복사합니다. 채 GPT에 붙여
넣습니다. 답변을 받습니다. 다시
엑셀로 가져옵니다.이 과정에서 문제가
생깁니다. 어떤 탭을 봐야 하는지,
어떤 컬럼이 중요한지, 어떤 수식이
연결되어 있는지 AI에게 계속
설명해야 합니다. 그런데 이제 흐름이
바뀝니다. AI가 파일 가까이 붙으면
사람의 역할도 바뀝니다. 이제 사람은
데이터를 옮기는 사람이 아니라 작업을
지시하고 검토하는 사람이 됩니다.
예전에는이 데이터를 읽고 요약해
줘라고 물어봤다면 이제는이 탭을
기준으로 비용 구조를 정리해 줘.
결제되기 것만 찾아줘. 운영 리포트
요약이 적절해 이렇게 요청할 수 있는
방향으로 가는 겁니다. 크랩 일에
바로 쓰는 AI. 오늘은 채 GPT가
엑셀 안으로 들어오면서 AI가 실제
업무 파일에 붙기 시작했다는 흐름을
살펴봤습니다.이
기능이 중요한 이유는 단순히 엑셀에서
채 GPT를 쓸 수 있기 때문이
아닙니다. 이제 AI가 우리가 실제로
일하는 표를 보고 수식을 설명하고
데이터를 정리하고 리포트 초안까지
만들 수 있는 방향으로 가고 있기
때문입니다. 다만이 말이 엑셀을
몰라도 된다는 뜻은 아닙니다. 오히려
이제는 수식을 많이 외우는 능력보다
데이터 구조를 읽고 업무 목적을
정하고 AI에게 정확한 작업 범위를
맡기는 능력이 더 중요해질 거라고
생각합니다. 그렇게 우리 업무도
달라지겠죠. AI가 정리한 결과가
실제 업무 기준에 맞는지, 누락된
데이터는 없는지, 수식이나 가정이
맞는지는 마지막에 사람이 확인해야
합니다. 기능적인 업무를 빠르게
처리하는 실무자에서 실무 이해도를
바탕으로 AI에게 업무를 맡기고
결과를 계속 확인하는 AI 매니저의
역할로 자연스럽게 바뀌는 거죠. 기능
하나가 업데이트 된 것처럼 보이지만
사실은 많은 것이 바뀔 수 있겠다는
생각이 드는 업데이트입니다. 다음
실전편에서는이 기능을 실제 업무에
적용해 보겠습니다. 엑셀 데이터
자동화 테스트라고 할까요? 깨끗한
매출 데이터, 지저분한 비용 데이터,
고객 무의와 운영 이슈까지 넣고 채
GPT가 어디까지 정리하고 분석할 수
있는지 직접 보겠습니다. 이번
업데이트의 핵심은 엑셀에 채봇이 하나
붙었다는게 아닙니다. AI가 우리가
실제로 일하는 파일 안으로 들어오기
시작했다는 것 이게 핵심입니다.
지금까지 어렵지 않게 일에 바로 쓰는
AI 크랩이었습니다.
