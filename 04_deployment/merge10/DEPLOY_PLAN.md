## 1. 배포 전 요건 점검

| # | 요건 | 상태 | 비고 |
|---|------|------|------|
| 1 | 빌드 통과 | ✅ | `npm run build` — 3/3 export 성공 |
| 2 | 정적 export | ✅ | `output: 'export'`, `out/` 생성 |
| 3 | 검증 스크립트 | ✅ | 파싱·평탄화·헤더추정·자동매칭·병합 전부 통과 |
| 4 | 비밀값 없음 | ✅ | `.env` 미사용, 서명키는 git 제외 |
| 5 | 개인정보 미수집 | ✅ | 파일이 브라우저 밖으로 나가지 않음 |
| 6 | 약관 페이지 | ⚠️ | **`[대표 확인 필요]` 4곳 미완** |
| 7 | 하위 경로 대비 | ✅ | `trailingSlash: true` |

**결론: 6번만 해결되면 배포 가능.**

## 3. 배포 경로 (확정)

**1순위: Cloudflare 임시 배포**
- 계정 불필요, 비용 0원
- `wrangler --temporary` 방식
- 수명 제한 있음 (데모 확인용)
- 스킬: `cloudflare-temporary-deploy`

**2순위: GitHub Pages**
- `gh` CLI 로그인됨, 무료
- 정적 사이트 그대로 배포 가능
- 비공개 저장소 기본
- 스킬: `publish-site`

**선택 기준:** 임시 URL로 먼저 확인 → 반응 좋으면 정식 경로.

---

## 4. 실행 절차 (승인 후)

```
1. 약관 4개 항목 반영 (개발팀, 10분)
2. npm run build 재실행 (5분)
3. Cloudflare 임시 배포 (10분)
4. URL 직접 열어 첫 화면 확인 (5분)
5. DEPLOY_LOG.md 기록
6. painpoints.json status → launched
7. 대표이사 보고 (PDF)
```

**예상 소요: 30분 ~ 1시간**
