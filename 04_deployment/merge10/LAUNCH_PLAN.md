# Merge10 출시 홍보 계획 (초안 — 실제 게시는 대표 승인 후)

**작성일:** 2026-10-03
**상태:** 초안 (게이트 3 승인 후 대표가 직접 게시 또는 별도 지시)
**근거:** `10jo-deploy` 스킬 8단계

---

## 1. 제품 한 줄 정의

**Merge10** — 여러 엑셀/CSV 파일을 브라우저에서 한 번에 합치는 도구.
**파일이 서버로 전송되지 않는다.** 회사 재무·인사 데이터를 다루는 경리·총무 담당자를 위한 도구.

---

## 2. 타깃 고객

| 구분 | 내용 |
|------|------|
| 1차 | 회사 경리·총무 담당자 (지점별 매출·지출 파일 취합) |
| 2차 | 프리랜서·소규모 사업자 (거래처별 정산 파일) |
| 3차 | 데이터 정리 업무 담당자 (리서치·운영) |

**핵심 고통:** 매달 반복되는 파일 취합. 컬럼 이름이 파일마다 달라 수작업 매칭. 파일을 외부 서비스에 올리기 어려운 민감 데이터.

---

## 3. 차별점 (경쟁 도구 대비)

| 항목 | 기존 도구 | Merge10 |
|------|-----------|---------|
| 파일 전송 | 서버 업로드 | **브라우저 내 처리 (전송 없음)** |
| 컬럼 매칭 | 수동 | 자동 매칭 (100% 검증) |
| 셀 병합 처리 | 미지원 | 평탄화 자동 처리 |
| 가격 | 구독 | **단건 (2,900원 / 39,000원)** |
| 회원가입 | 필요 | 불필요 |

## 5. 게시물 초안 (3종)

### 초안 A — 문제 제기형

> 매달 말이면 지점별 매출 파일 12개를 하나로 합칩니다.
> 문제는 파일마다 컬럼 이름이 "지점"/"지점명"/"매장"으로 다르다는 것.
> 수작업으로 맞추다 보면 30분이 사라집니다.
>
> 이걸 자동으로 해주는 도구를 만들었습니다.
> 파일은 서버로 안 올라갑니다 — 브라우저 안에서만 처리됩니다.
>
> (링크)

### 초안 B — 보안 관점형

> "엑셀 합쳐주는 사이트" 검색하면 다들 파일을 업로드하라고 합니다.
> 회사 인사 데이터나 급여 파일을 남의 서버에 올리는 게 찜찜하신 분들.
>
> Merge10은 파일을 업로드하지 않습니다.
> 브라우저 안에서만 처리하고, 서버로 아무것도 보내지 않습니다.
> 회원가입도, 개인정보 수집도 없습니다.
>
> (링크)

### 초안 C — 전환 유도형

> Merge10 가격 안내
> · 24시간 패스 2,900원 — 급할 때 한 번만
> · 평생 이용권 39,000원 — 매달 나가는 돈 없음
>
> 구독 아닙니다. 한 번 사면 계속 씁니다.
> 파일은 서버로 전송되지 않습니다.
>
> (링크)
