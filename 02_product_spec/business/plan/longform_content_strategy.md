## 서문 — 이 문서의 사용법

이 문서는 **10조 롱폼(10jo Longform) 콘텐츠 브랜치의 기획·SEO 전략 수립 문서**다. 회사 규칙 7-5절에 따라 10조 이사가 5개 사업 브랜치를 관리·지휘하며, 그중 **10조 롱폼(콘텐츠)** 브랜치의 활성화와 SEO 전략을 수립하는 것이 목표다.

**사용 규칙:**
1. 이 문서는 대표가 롱폼 콘텐츠 사업의 방향성을 결정하는 기준서다.
2. 수석은 이 문서의 실행 계획을 기준으로 업무를 배정한다.
3. 대표는 승인 요청 항목에 서명한다.
4. 수치는 모두 출처가 있거나 "(추정)"으로 표기한다.

**이 문서의 근거:**
- 회사 규칙 7-5절 (10조 이사 총괄 체제)
- 10조 스튜디오 사업계획서 v4.0
- 불편 데이터 48개 항목 (painpoints.json)
- 10조 이사 스킬 `10jo-director-ops`

# 5. SEO 전략

## 5.1. 키워드 전략

### 5.1.1. 키워드 선정 기준

1. **검색량** — 월간 검색량 1,000 이상
2. **경쟁도** — 경쟁 강도 중간 이하
3. **관련성** — 10조 스튜디오의 불편 해결과 직접 관련
4. **수익성** — 광고·제휴 연결 가능

### 5.1.2. 키워드 카테고리

| 카테고리 | 예시 키워드 | 검색량 (추정) | 경쟁도 |
|----------|-------------|--------------|--------|
| 엑셀 자동화 | "엑셀 자동화", "엑셀 매크로" | 높음 | 높음 |
| AI 도구 | "AI 도구 추천", "AI 업무 효율" | 높음 | 높음 |
| 업무 자동화 | "업무 자동화", "반복 업무 줄이기" | 중간 | 중간 |
| 1인 사업자 | "1인 사업자 자동화", "혼자 일하기" | 중간 | 중간 |
| 프리랜서 | "프리랜서 도구", "프리랜서 업무" | 중간 | 중간 |

### 5.1.3. 롱테일 키워드 전략

- "엑셀 자동화" → "엑셀 데이터 취합 자동화 방법"
- "AI 도구" → "업무용 AI 도구 추천 2026"
- "업무 자동화" → "반복 업무 자동화 도구 비교"

## 5.2. 온페이지 SEO

### 5.2.1. 제목 태그 (Title Tag)

- 키워드를 앞부분에 배치
- 60자 이내
- 클릭 유도 문구 포함

### 5.2.2. 메타 설명 (Meta Description)

- 키워드 포함
- 150자 이내
- 클릭 유도 문구 포함

### 5.2.3. 헤딩 구조

- H1: 제목 (1개)
- H2: 주요 섹션 (3-5개)
- H3: 하위 섹션 (필요시)

### 5.2.4. 본문 최적화

- 키워드 밀도 1-2%
- 이미지 alt 텍스트 포함
- 내부 링크 연결
- 외부 링크 (신뢰성 있는 소스)

### 5.2.5. URL 구조

- 키워드 포함
- 짧고 명확
- 하이픈으로 구분

## 5.3. 오프페이지 SEO

### 5.3.1. 백링크 구축

| 디렉토리 제출 | 블로그 디렉토리 등록 | 쉬움 |

### 5.3.2. 소셜 시그널

- 페이스북 공유
- 트위터 공유
