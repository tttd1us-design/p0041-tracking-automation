**Zapier의 진짜 무기 3가지:**
1. **8,000개 앱 연동** — 10년간 쌓은 파트너십. 복제 불가
2. **태스크 과금** — 쓰면 쓸수록 매출이 는다
3. **투자 없이 흑자** — 자본 압박이 없어 장기전 가능

## 2.2. Zapier의 진짜 약점 5가지

| 약점 | 구체 내용 | 우리의 대응 |
|---|---|---|
| **① 인지 부담** | "무엇을 자동화할지" 고객이 설계해야 함. 빈 화면에서 시작 | **고통을 먼저 특정 → 완성된 도구 제공.** 빈 화면 없음 |
| **② 한국 미지원** | 네이버·카카오·토스·홈택스·더존 연동 빈약. 한국어 문서 부실 | **한국 서비스 네이티브 연동** |
| **③ 비싸다** | 월 $29.99 ≈ 4만 원. 한국 중소사업자에 부담 | **월 9,900원부터** (1/4 가격) |
| **④ 예측 불가 과금** | 태스크 초과 $0.06 — 요금 폭탄 공포 | **정액 구독.** 초과 요금 없음 |
| **⑤ 학습 곡선** | Zap·Trigger·Action·Filter 개념 학습 필요 | **업로드 → 버튼 → 다운로드.** 학습 0분 |
| **⑥ 무료 티어 함정** | 2단계 제한 → 체험하고도 가치 못 느낌 | **무료 3회 완전 기능.** 가치를 먼저 경험 |

## 2.3. 결정적 차이 — 판매하는 것이 다르다

```
Zapier:  [레고 블록 8,000개] → 고객이 조립해야 함
         "무엇을 만들지 모르면 아무것도 못 만든다"

10조:    [완성된 가구 30개] → 바로 쓴다
         "무엇이 문제인지 우리가 안다"
```

**Zapier 고객의 실제 실패:** 계정 만들고, 앱 2개 연결하고, 트리거 설정하고, 필터 넣다가 포기. Zapier는 이 사람에게 돈을 못 받는다.

**우리 고객의 경험:** 파일 올리고 버튼 누르면 30초 만에 끝난다. 그리고 9,900원을 낸다.

## 2.4. 우리가 Zapier보다 나은 이유 (정직한 버전)

**우리가 못 이기는 것:** 앱 연동 수(8,000개), 브랜드 인지도, 자본력, 글로벌 규모.
**우리가 이기는 것:** 한국 시장 점유, 사용 편의성, 가격, 속도, 니치 집중.

**결론:** 우리는 Zapier를 **정면에서 이기지 않는다.** Zapier가 **경제성 때문에 들어올 수 없는 한국 초협소 니치**를 점유한 뒤, 그 니치들을 모아 **동아시아 자동화 플랫폼**으로 확장한다.
