## 1. Senja.io — 후기 수집 마이크로SaaS

| 항목 | 내용 |
|------|------|
| **서비스명** | Senja.io |
| **창업자** | Wilson Wilson (@euboid), Olly Meakings (@helloitsolly) — 2인 팀, 온라인에서 만나 원격 협업 |
| **창업 연도** | 2022 |
| **국가** | 영국/나이지리아 (원격) |
| **해결한 문제** | 크리에이터, 프리랜서, 에이전시, SaaS 기업 등이 고객 후기(testimonial)를 수집하고 표시하는 것이 번거로움. 후기 수집은 까다롭고, 이쁘게 표시하는 것은 더 까다로움. |
| **가격 정책** | 구독형 SaaS. 프리 티어 + 유료 플랜 (구체 금액 공개되지 않음) |
| **실제 매출 수치** | ~$1M ARR / ~$83K MRR (2025년 11월 기준, 창업자 공개 보고) |
| **고객 수** | 3,000+ 유료 고객 (2025년 11월) |
| **자본 조달 여부** | 부트스트랩 (외부 투자 없음) |
| **첫 고객 획득 채널** | Build-in-public (X/트위터, 블로그에 MRR 마일스톤 공개), 제품 주도 성장 (프리 티어 + 입소문) |
| **개발 기간 / 1인 개발 여부** | 2인 팀. 약 3년 9개월 만에 $1M ARR 달성 |
| **출처 URL** | https://solopreneurship.eu/articles/case-lab-senja-bootstrapped-micro-saas-1m-arr |

**핵심 교훈:** 좁은 문제(후기 수집) → 빠르게 출시하고 과금 → Build-in-public → 제품 주도 성장 → 부트스트랩으로 복리 성장. 4년 걸림.

## 2. MicroAcquire — 스타트업 인수 마켓플레이스

| 항목 | 내용 |
|------|------|
| **서비스명** | MicroAcquire (현재 Acquire.com) |
| **창업자** | Andrew Gazdecki |
| **창업 연도** | 2020 |
| **국가** | 미국 |
| **해결한 문제** | 부트스트랩 창업자가 잠재적 매수자를 찾는 것이 어려움. 중개 수수료 없이 스타트업 인수·매각을 연결하는 마켓플레이스 필요. |
| **가격 정책** | 프리미엄 멤버십 $290/년 (2021년 2월 기준, 이후 $390/년으로 인상 예정). 매각 수수료 없음. |
| **실제 매출 수치** | $265,000 ARR (2021년 2월 기준, 창업자 AMA 공개). 월 30-40% 성장. |
| **고객 수** | 40,000 등록 사용자, 200+ 성공적인 인수 건 (2021년 2월) |
| **자본 조달 여부** | 부트스트랩 (이전 회사 Bizness Apps를 $10M+ ARR로 키워 2018년 PE에 매각한 경험 보유) |
| **첫 고객 획득 채널** | 1) 아웃바운드 콜드 이메일 (창업자·매수자 대상), 2) Product Hunt 런치 #1 Product of the Day → 1,000+ 가입자, 3) 소셜 미디어 빌드인 퍼블릭 |
| **개발 기간 / 1인 개발 여부** | 1인 창업자. 12개월 내 $265K ARR 달성. |
| **출처 URL** | https://www.indiehackers.com/post/ama-bootstrapped-my-saas-to-265k-arr-in-12-months-0d058e9a90 |

**핵심 교훈:** 콜드 이메일 + Product Hunt 런치. 이전 엑시트 경험을 활용한 신뢰 구축.

**핵심 교훈:** API SaaS는 1인에게 적합 (UI 적음, 개발자 고객 단가 높). 아이디어 검증 없이 "내가 사용자" 방식으로 시작.

| **첫 고객 획득 채널** | 1) X(트위터) 8년간 구축한 28,000 팔로워 오디언스, 2) Product Hunt Product of the Day 수상, 3) 수동 고객 온보딩 (블로그 마이그레이션 직접 지원), 4) 입소문 + SEO |
| **개발 기간 / 1인 개발 여부** | 1인 개발. 2022년 5월 출시 ~ 2024년 6월 매각 (약 2년). |
| **매각** | 2024년 6월, $250,000 (연매출의 ~3.5배). 매수자: Tibo Louis-Lucas (Tweet Hunter 엑시트 창업자) |
| **출처 URL** | https://small-start.com/en/cases/global-feather-250k-exit/ |

**핵심 교훈:** 오디언스가 첫 시장. 수동 지원이 분배 장치가 됨. 단일 플랜 $40/월이 매각에 유리.

## 종합 분석

### 공통 패턴

1. **부트스트랩 압도적 다수 (12/12):** 모든 사례가 외부 투자 없이 시작. 일부는 이전 엑시트 자금 활용.
2. **1인 또는 2인 팀:** 10개 사례가 1인, 2개 사례가 2인.
3. **Build-in-public이 핵심 성장 채널:** 8개 사례에서 X(트위터) 오디언스, 공개 수익 대시보드, 블로그 마케팅이 주요 채널.
4. **Product Hunt 런치:** 4개 사례에서 Product Hunt #1 또는 상위 랭크 달성.
5. **유료 광고 거의 안 씀:** 대부분 유기적 성장, 콘텐츠, 커뮤니티에 의존.
6. **좁은 니즈, 깊은 워크플로우:** 후기 수집, 스크린샷, 스토어 로케이터 등 "지루하지만" 반복적인 문제.
7. **API SaaS가 1인에게 유리:** ScreenshotOne, Bannerbear 등 API 모델은 UI 부담이 적고 개발자 고객 단가가 높음.

### 매출 규모 분포

- **$1M+ ARR:** 4개 (Senja, Steady, Bannerbear, Fomo)
- **$100K-$1M ARR:** 5개 (MicroAcquire, Feather, Potion, FeedbackPanda, Storemapper)
- **$10K-$100K ARR:** 3개 (ScreenshotOne, Earlyname, Nomad List)

### 엑시트 사례 (6개)

| 서비스 | 매각 금액 | 배수 | 매수자 |
|--------|----------|------|--------|
| Feather | $250,000 | ~3.5x 연매출 | Tibo Louis-Lucas (개인) |
| Earlyname | $10,500 | 30x 월매출 | 경험 많은 개발자 (개인) |
| Potion | $300,000 | ~4x 연매출 | Bruno Morency (개인) |
| FeedbackPanda | 7자리수 (비공개) | — | SureSwift Capital |
| Fomo | 7자리수 (비공개) | — | Relay Commerce |
| Storemapper | 비공개 | — | SureSwift Capital |

### 10조 스튜디오에 시사점

1. **첫 고객은 오디언스/커뮤니티에서:** 모든 사례가 콜드 콘택트, 커뮤니티 참여, 콘텐츠로 첫 고객 확보.
2. **$50-100/월 단가가 현실적:** 대부분 $10-$200/월 범위. 너무 낮은 가격은 생존 불가.
3. **Build-in-public이 마케팅 예산 0의 대안:** 공개 수익 보고, 개발 과정 공유가 신뢰와 고객을 동시에 생성.
4. **엑시트는 현실적 옵션:** $350 MRR도 $6.5K에 매각 가능. $40K MRR은 3개 오퍼 유치.
5. **개발 기간 3주~6개월:** 대부분 짧은 기간에 MVP 출시 후 반복적 개선.
