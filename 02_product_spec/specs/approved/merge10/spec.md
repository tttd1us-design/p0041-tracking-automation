## 0. 재정의 경위 (중요)

원래 계획은 **범용 엑셀 자동화**였으나, 검증에서 두 가지가 드러났다.

1. 크몽에서 엑셀 자동화는 **확립된 유료 시장**이다 (3만~250만 원, 네오웍스 누적 140건+).
2. 그러나 전부 **일회성 외주(SI)** 구조이고, 이유는 명확하다 — 비정형 예외가 무한해 규격화가 안 되기 때문.

안티그래비티 제3자 검토:
> "예외 케이스가 무한대에 가까워 범용 자동화로 규격화하기가 사실상 불가능합니다. 결국 저단가 커스텀 용역(SI)으로 전락하게 됩니다."

**그래서 범위를 좁힌다: "예외가 구조적으로 없는 단일 반복 작업"만 제품화한다.**

## 1. 문제

직장인이 **매월/매주** 여러 부서·여러 지점에서 온 엑셀/CSV 파일을 **하나로 합치는** 작업을 반복한다.
파일마다 컬럼 순서가 다르고, 헤더 행 위치가 다르고, 시트명이 제각각이라 매번 손으로 맞춘다.

크몽 실제 상품 설명에서 확인된 장면:
> "매일 엑셀 정리에 30분, 주문 내역 옮겨 적기에 1시간, 사이트에서 자료 내려받아 취합하는 데 반나절"

> "여러 사이트/프로그램에 흩어진 데이터를 모아 하나로 정리"

**핵심:** 이 작업은 **입력이 통제되어 있다.** 파일 개수는 많아도 양식은 같다.
→ 비정형 예외 문제를 구조적으로 회피한다.

## 2. 타깃 고객

**가장 먼저 쓸 사람:** 매월 결산·정산을 하는 **중소기업 경리·총무 담당자 1명**.

- 부서별로 받은 지출/매출 파일 10~50개를 하나로 합쳐야 함
- 엑셀은 쓰지만 VBA·Power Query는 모름
- 지금은 **수동 복사붙여넣기**로 2~3시간 소요

**지금 쓰는 대안과 한계:**
- 수동 복붙 → 파일 50개면 2~3시간, 실수 발생
- 크몽 외주 → 건당 5~25만 원, 매번 의뢰해야 함, 양식 바뀌면 재의뢰
- Power Query → 학습 곡선, 다음 달에 기억 못 함
- VBA → 개발 지식 필요

## 3. 해법 한 줄

**여러 엑셀/CSV 파일을 한 번에 드래그하면, 컬럼을 자동으로 맞춰 하나의 파일로 합쳐주는 웹 도구.** (파일은 브라우저 밖으로 나가지 않는다)

## 4. 핵심 기능 (3개)

### 기능 1: 다중 파일 드래그 업로드 + 구조 자동 인식
- **사용자가 하는 일:** 파일 10~50개를 한 번에 드래그
- **화면이 보여주는 것:** 파일 목록(행 수), 각 파일의 컬럼명, **자동 매칭된 컬럼 대응표**
- **완료 기준:** 50개 파일 업로드 시 5초 내 인식, 컬럼 자동 매칭 정확도 90% 이상

### 기능 2: 컬럼 매칭 확인·수정
- **사용자가 하는 일:** 자동 매칭이 틀린 컬럼만 드롭다운으로 수정
- **화면이 보여주는 것:** 원본 컬럼명 ↔ 통합 컬럼명 대응표, 미매칭 컬럼 경고
- **완료 기준:** 수정 즉시 미리보기 갱신, 매칭 규칙을 다음 파일에도 재사용

### 기능 3: 병합 실행 + 다운로드
- **사용자가 하는 일:** "병합" 버튼 클릭
- **화면이 보여주는 것:** 통합 결과 미리보기(상위 100행), **총 몇 행이 합쳐졌는지**, 원본 파일별 기여 행 수, `.xlsx` 다운로드
- **완료 기준:** 원본 데이터 손실 0, 다운로드 파일이 Excel에서 정상 개방, 병합 로그 제공

## 5. 만들지 않는 것 (MVP 범위 밖)

- **비정형 서식 처리** — 셀 병합·다단 헤더·이미지 포함 시트는 **명시적으로 거부**하고 경고를 띄운다 (SI 전락 방지의 핵심)
- 가로형→세로형 변환 (별도 아이템으로 분리)
- 중복 제거·데이터 정제 (별도 아이템)
- 자연어 AI 변환
- 회원가입·로그인 (프리셋은 localStorage)
- 서버 업로드·저장 — **절대 안 함** (브라우저 내 처리)
- 모바일
- 실제 결제 연동 (버튼만)
- 10만 행 초과 처리 (MVP는 파일당 5만 행 이하)

## 6. 화면 흐름 (단일 페이지)

1. **랜딩 + 업로드:** "여러 엑셀 파일을 한 번에 드래그하세요" + 드롭존
   - 하단에 보안 문구: **"파일은 내 컴퓨터 밖으로 나가지 않습니다"**
2. **인식:** 파일 목록 + 컬럼 자동 매칭표 표시
3. **확인:** 틀린 매칭만 수정 → 미리보기 갱신
4. **병합:** 버튼 클릭 → 결과 요약(총 행 수, 파일별 기여) + 다운로드
5. **결제 유도:** 무료 3회 후 "무제한 — 월 9,900원" (버튼만, `TODO(결제연동-승인필요)`)

## 7. 가격 가설

| 플랜 | 가격 | 내용 |
|---|---|---|
| 무료 | 0원 | 3회 병합 (1회당 파일 5개까지) |
| **Pro** | **월 9,900원** | 무제한 병합, 파일 무제한, 프리셋 저장 |

**근거:**
- 크몽 외주는 건당 4.9만~25만 원 (일회성). 우리는 월 9,900원으로 **매월 반복**을 잡는다.
- 안티그래비티 권고: "월 9,900원 구독형을 권장. 저렴한 구독형이 지속 업데이트와 고객 락인에 훨씬 유리."
- 경리 담당자의 월 2~3시간 절약 → 시급 1만 원 기준 **월 2~3만 원 가치**. 9,900원은 그 1/3.

**결제는 연동 지점만.** 실결제 금지. 승인 후 토스페이먼츠/Stripe.

## 8. 성공 지표

**출시 2주 안에 확인할 숫자 하나:**
> 방문자 중 **실제 병합을 1회 이상 완료한 비율** (목표: 30% 이상)

이유: 결제 버튼 클릭률보다 **먼저 "써봤는가"**를 봐야 한다. 파일을 올려 결과를 받아가는 사람이 진짜 수요다.
(2차 지표: 3회 소진 후 결제 버튼 클릭률 — 목표 10%)

## 9. 기술 메모

**스택:** Next.js (App Router) + TypeScript + Tailwind CSS

**핵심 라이브러리:**
- `xlsx` (SheetJS) — 파싱·생성. **무료 오픈소스**
- 상태: React `useState` + Zustand (경량)
- 프리셋: 브라우저 `localStorage` (서버 DB 없음)

**배포:** `output: 'export'` 정적 사이트 → GitHub Pages 또는 Cloudflare Pages (무료). 서버 불필요.

**반드시 지킬 것:**
- 모든 파일 처리는 **브라우저 메모리 안에서만**. fetch로 파일을 어디에도 보내지 않는다.
- 화면에 "파일은 내 컴퓨터 밖으로 나가지 않습니다" 문구를 상시 표시 (핵심 구매 장벽 해소 + 차별점)

**법적 리스크:**
- **개인정보보호법:** 서버 처리 시 개인정보처리자 의무 발생 → **브라우저 내 처리로 회피**. 파일이 서버에 도달하지 않으므로 처리자 해당 없음. 이 설계가 법적 방어선이다.
- **전자상거래법:** 유료 판매 시 통신판매업 신고 필요. 사업자 정보 표시 의무 → 결제 연동 승인 시점에 처리. MVP에서는 결제 버튼만.
- **AI기본법:** 해당 없음 (AI 미사용).
- **약관:** 개인정보를 받지 않으므로 개인정보처리방침은 최소. 이용약관만 필요.

## 10. 경쟁·대체재

| 대안 | 가격 | 약점 |
|---|---|---|
| 수동 복붙 | 0원 | 파일 50개면 2~3시간 |
| 크몽 외주 | 건당 4.9만~25만 원 | 매번 재의뢰, 양식 바뀌면 다시 |
| Power Query | 무료 | 학습 곡선, 다음 달에 기억 못 함 |
| Excel 병합 기능 | 무료 | 컬럼 순서 다르면 실패, 위치 지정 필요 |
| Zapier/Make | 월 $20~ | 엑셀 병합 특화 아님, 한국 미지원 |
| SheetXAI / ElyxAI | $20~€29/월 | 영어 중심, 비쌈 |

**차별점 3개:**
1. **컬럼 자동 매칭** — 파일마다 순서가 달라도 맞춰줌 (엑셀 기본 병합은 이걸 못 함)
2. **브라우저 내 처리** — 재무 데이터를 서버에 안 올림 (경리 담당자의 최대 거부감 해소)
3. **월 9,900원** — 크몽 건당 5만 원 대비 1/5, 매월 반복 가능

## 11. Grill 결과 (남은 약점, 숨기지 않음)

| 공격 | 답 | 남은 약점 |
|---|---|---|
| "엑셀에 병합 기능이 있지 않나" | 컬럼 순서가 다르면 실패. 우리는 자동 매칭 | **엑셀 기본 기능과의 차이를 3초 안에 보여줘야 함** |
| "누가 돈을 내나" | 크몽에서 건당 5만 원 결제 실적 존재 | **구독 전환은 미검증** (일회성 지불자는 구독을 싫어할 수 있음) |
| "파일 50개를 브라우저가 감당하나" | SheetJS는 가능. 5만 행 이하로 제한 | **대용량에서 브라우저 메모리 한계** |
| "비정형 서식은" | **명시적으로 거부**하고 경고 | 거부당한 사용자가 이탈 (의도된 트레이드오프) |

**가장 큰 미검증 리스크:** 일회성 지불 성향이 강한 시장에서 **구독**이 받아들여질지. → 2주 내 결제 버튼 클릭률로 판정.

## 12. 리스크

1. **치명적:** 구독 모델 거부 (시장이 일회성 지불에 익숙) → 무료 체험 후 전환율로 조기 판정, 안 되면 일회성 크레딧 모델로 전환
2. **높음:** 엑셀 기본 기능으로 충분하다는 인식 → 랜딩에서 "컬럼 순서 달라도 됨"을 즉시 시연
3. **중간:** 브라우저 메모리 한계 → 5만 행 제한 명시
4. **낮음:** 기술 구현 난이도 → SheetJS 성숙, 순수 클라이언트 로직
