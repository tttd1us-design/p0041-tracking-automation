# [MVP 1호] 엑셀 데이터 취합 자동화 도구 — spec.md

**제품명:** ExcelMerge Pro (엑셀 머지 프로)  
**버전:** 1.0  
**작성일:** 2026-10-02  
**상태:** 개발 대기  
**우선순위:** P0 (최우선)

---

## 1. 문제 정의 (Problem Statement)

### 1.1. 고통 설명
직장인, 1인 기업 사장, 마케터가 매일/매주 반복되는 엑셀 데이터 취합·복사붙여넣기·수식 작업에 수시간을 소요하며, 데이터 규모가 수천~수만 건이 되면 실수 가능성과 계산 지연이 급증한다.

### 1.2. 타깃 사용자
- **주요:** 직장인, 1인 기업 사장, 마케터
- **부수:** 데이터 담당자, 영업 관리자

### 1.3. 현재 대안 (Alternatives)
- 수동 복사붙여넣기
- VLOOKUP 수식 작성
- 외부 엑셀 강의 수강
- VBA 매크로 (개발 지식 필요)

### 1.4. 고통 강도
- **빈도:** 매일/매주 반복
- **심각성:** 수시간 소요, 실수 가능성, 데이터 규모 증가 시 급증
- **지불 용의:** 높음 (생산성 향상 위해 AI 도구 구매 의사 있음)

---

## 2. 해법 정의 (Solution)

### 2.1. 핵심 가치 제안
"여러 엑셀 파일을 드래그 한 번으로 합치고, 자동으로 중복 제거·정렬·집계까지 끝내는 원클릭 엑셀 자동화 도구"

### 2.2. 핵심 기능 (MVP 범위)

| 기능 | 설명 | 우선순위 |
|---|---|---|
| **다중 파일 업로드** | 여러 엑셀 파일(.xlsx, .csv)을 드래그&드롭 또는 파일 선택으로 업로드 | P0 |
| **자동 시트 합치기** | 업로드된 파일의 모든 시트를 하나의 시트로 자동 합침 | P0 |
| **중복 데이터 제거** | 설정된 기준 열(예: 날짜, 제품명) 기반 중복 행 자동 제거 | P0 |
| **데이터 정렬** | 날짜, 숫자, 텍스트 기준 오름차순/내림차순 정렬 | P1 |
| **기본 집계** | SUM, COUNT, AVERAGE 등 기본 집계 함수 자동 적용 | P1 |
| **결과 다운로드** | 처리된 결과를 .xlsx 파일로 다운로드 | P0 |

### 2.3. 비기능 요구사항
- **성능:** 1만 행 이하 데이터 처리 시간 10초 이내
- **보안:** 업로드된 데이터는 서버에 저장하지 않고 메모리에서만 처리
- **호환성:** Chrome, Edge, Safari 최신 버전
- **파일 형식:** .xlsx, .csv 지원

## 3. 기술 스택 (Tech Stack)

| 계층 | 기술 | 선정 이유 |
|---|---|---|
| **프론트엔드** | React + Vite | 빠른 개발, 컴포넌트 재사용 |
| **엑셀 처리** | SheetJS (xlsx) | 브라우저에서 엑셀 파일 읽기/쓰기 |
| **백엔드** | Node.js + Express | 간단한 API 서버 |
| **배포** | Vercel (프론트) + Railway (백엔드) | 무료 티어, 빠른 배포 |
| **결제** | Stripe / 토스페이먼츠 | 구독 모델 지원 |

---

## 4. 사용자 경험 (UX) 플로우

```
1. 메인 페이지 접속
   ↓
2. 파일 업로드 영역에 엑셀 파일 드래그 (또는 클릭하여 선택)
   ↓
3. 업로드된 파일 목록 표시 (파일명, 시트 수, 행 수)
   ↓
4. 옵션 설정 (중복 제거 기준 열, 정렬 기준, 집계 함수)
   ↓
5. [자동 처리] 버튼 클릭
   ↓
6. 처리 결과 미리보기 (상위 100행)
   ↓
7. [다운로드] 버튼 클릭 → .xlsx 파일 저장
```
