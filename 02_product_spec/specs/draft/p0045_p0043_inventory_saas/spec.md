# 재고관리 SaaS — 제품 명세

- 원천 불편: P-0045 (재고 실시간 동기화 안 됨) + P-0043 (유료 전환 미리 안내 안 함)
- 작성일: 2026-10-04 / 상태: 승인 대기
- 통합 아이템: P-0045 + P-0043 (재고관리 SaaS 통합)

---

## 1. 문제

**P-0045:** 온라인 스토어와 오프라인 매장의 재고가 실시간으로 동기화되지 않음. 재고 불일치로 인한 주문 취소·고객 불만 발생. 레딧 r/smallbusiness "Inventory tracking" 스레드에서 다수 사용자가 동일 문제 공유.

**P-0043:** 재고관리 앱이 무료 체험 후 유료 전환을 미리 안내하지 않음. 사용자가 데이터 입력 후 유료 결제 요구받아 불쾌감. 박스히어로 리뷰 12건 저평점: "유료라는 점을 왜 미리 공지하지 않았을까요?", "2번째 달부터 100개 이상 등록시 월 2만원 내야 해요", "무료인 것처럼 하다가 고생해서 물품 다 등록했더니 유료라고 하네요".

**통합 문제:** 재고관리 SaaS 시장에서 ① 실시간 동기화 기능 부재와 ② 유료 전환 정책 불투명이 가장 큰 불만. 두 문제를 동시에 해결하는 제품이 없음.

---

## 2. 타깃 고객

**1인 온라인 판매자 (스마트스토어, 쿠팡, 네이버 스마트스토어 판매자)**

- 현재 대안: 엑셀 수동 관리, 박스히어로 (유료 $30/월), SalesDocks (월 9,900원~)
- 대안의 한계:
  - 엑셀: 실시간 동기화 불가, 수식 복사 붙여넣기 실패로 데이터 날아감 (P-0042)
  - 박스히어로: 유료 전환 불투명, 다중 위치 관리 미흡, 기능 제한 (P-0043, P-0045)
  - SalesDocks: 무료 플랜 제한적 (상품 50개, 하루 3건)

---

## 3. 해법 한 줄

**온라인·오프라인 재고를 실시간으로 동기화하고, 무료 플랜에서도 핵심 기능을 제한 없이 제공하며, 유료 전환 정책을 100% 투명하게 공개하는 재고관리 SaaS.**

---

## 4. 핵심 기능 (최대 3개)

### 4.1 실시간 재고 동기화
- 사용자가 하는 일: 온라인 스토어(스마트스토어, 쿠팰)와 오프라인 매장 재고를 등록
- 화면이 보여주는 것: 통합 재고 대시보드 (온라인 + 오프라인 합계, 실시간 업데이트)
- 완료 기준: 온라인 주문 발생 시 오프라인 재고에서 자동 차감, 재고 불일치 0건

### 4.2 투명한 가격 정책
- 사용자가 하는 일: 회원가입 전 가격 정책 확인
- 화면이 보여주는 것: 무료 플랜 기능 목록, 유료 플랜 가격, 전환 시점 명시
- 완료 기준: 회원가입 전 가격 정책 100% 노출, 유료 전환 7일 전 이메일 알림

### 4.3 엑셀 일괄 업로드/다운로드
- 사용자가 하는 일: 엑셀 파일로 재고 데이터 일괄 업로드, 백업
- 화면이 보여주는 것: 업로드 미리보기, 에러 행 표시, 다운로드 버튼
- 완료 기준: 1,000건 엑셀 업로드 30초 완료, 에러 행 0건

---

## 5. 만들지 않는 것

- 바코드 스캔 (MVP 제외, 2단계에서 추가)
- 다중 창고 관리 (MVP 제외, 2단계에서 추가)
- 유통기한 관리 (MVP 제외, 2단계에서 추가)
- 모바일 앱 (MVP는 웹 반응형만, 2단계에서 추가)
- 결제 연동 (MVP는 무료 플랜만, 유료 플랜은 2단계에서 추가)

---

## 6. 화면 흐름

1. **첫 화면:** 가격 정책 명시 (무료 플랜 기능, 유료 플랜 가격, 전환 시점)
2. **회원가입:** 이메일 + 비밀번호 (간편 가입)
3. **대시보드:** 통합 재고 현황 (온라인 + 오프라인 합계)
4. **핵심 행동:** 엑셀 업로드 → 재고 등록 → 실시간 동기화 확인
5. **결과:** 재고 불일치 0건, 주문 취소 0건
6. **결제 유도:** 무료 플랜 사용 중 유료 플랜 업그레이드 제안 (기능 제한 시)

---

## 7. 가격 가설

- **무료 플랜:** 월 0원, 상품 100개, 1명 사용자, 실시간 동기화, 엑셀 업로드/다운로드
- **유료 플랜:** 월 9,900원, 상품 무제한, 5명 사용자, 다중 창고, 바코드 스캔
- **가격 근거:** 박스히어로 $30/월 (약 4만원) 대비 1/4 수준, SalesDocks 9,900원/월과 동일
- **결제 연동:** MVP는 무료 플랜만, 유료 플랜은 2단계에서 Stripe 연동 (승인 필요)

---

## 8. 성공 지표

**출시 2주 안에 확인할 숫자 하나:** 무료 가입자 중 엑셀 업로드 완료율 50% 이상

## 9. 기술 메모

- **기본 스택:** Next.js + TypeScript + Tailwind CSS
- **데이터베이스:** PostgreSQL (무료: Supabase)
- **실시간 동기화:** WebSocket (Socket.io) 또는 Supabase Realtime
- **엑셀 처리:** SheetJS (xlsx)
- **외부 API:** 스마트스토어 API (네이버 공개 API), 쿠팡 API (쿠팡 파트너스)
- **법적 리스크:** 개인정보 처리 (판매자 정보), 전자상거래법 (약관 공개 의무)
- **호스팅:** Vercel (무료) 또는 Cloudflare Pages (무료)
