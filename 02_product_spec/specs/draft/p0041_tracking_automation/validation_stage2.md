### 2-1. 수기송장 입력의 비효율 (네이버 블로그)

**출처:** https://blog.naver.com/sukibon/222033529887
**제목:** 쇼핑몰 택배보내기 (feat. 수기송장)

**불만 사항:**
- 전자송장 시스템 문제로 송장 출력이 안 됨
- 수기송장 시스템으로 하면 주문서 뽑기, 상품준비, 주소적기, 주소와 택배내용물 대조 과정이 추가됨
- 발송 완료 후 전자송장은 엑셀파일에 송장번호를 자동으로 넣어서 한꺼번에 등록하면 되는데 수기송장은 하나하나 손으로 송장 번호를 쳐야 함
- 하나하나 주문자와 송장번호 대조해서 손으로 입력을 하다보니 가끔 엉뚱한 송장번호를 입력해버리는 오류 발생
- "1인 사업장에는 자동화 시스템을 갖추는게 매우 중요한것 같아요"

### 2-2. 스마트스토어 송장 입력 수동 작업 (네이버 블로그)

**출처:** https://blog.naver.com/yeon_ordinary_day/224306274002
**제목:** 스마트스토어 택배 보내는 방법 총정리｜초보 사장님 필수 가이드

**불만 사항:**
- 주문 처리 순서: 주문 확인 → 발주확인 처리 → 택배사 선택 → 송장번호 입력 → 상품 포장 → 택배 발송 → 배송중 상태 변경
- "송장 자동화 + 택배 계약 여부"가 핵심
- 기존: 수동 송장 입력 → 계약 후: 송장 자동 출력, 주문 → 송장 자동 등록 가능, 엑셀 업로드 가능
- 작업 시간이 절반 이하로 줄어듦

### 2-3. 위탁판매 자동화의 필요성 (네이버 블로그)

- 배송이 완료된 후 가장 중요한 업무 중 하나가 송장번호 입력
