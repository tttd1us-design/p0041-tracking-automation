# Excel Auto-Transform — 제품 명세

- 원천 불편: P-0001, P-0003, P-0007, P-0008 — 비개발 직장인의 엑셀 반복 작업(취합·복붙·가로형 데이터 정리·매크로 없이 자동화)
- 작성일: 2026-10-02 / 상태: 승인 대기

## 1. 문제

비개발 직장인이 매일/매주 반복되는 엑셀 데이터 취합·복사붙여넣기·수식 작업에 수시간을 소요한다. 데이터 규모가 수천~수만 건이 되면 실수 가능성과 계산 지연이 급증한다. 가로형으로 쌓인 데이터는 피벗테이블·VLOOKUP 등 기본 집계 기능을 쓸 수 없어 매번 수동 처리해야 한다. VBA·매크로를 시도하려면 시트명 불규칙·다수 시트·셀 위치 가변 등 수식만으로 풀 수 없는 벽에 부딪힌다. ChatGPT에 복사-붙여넣기하고 결과를 다시 엑셀로 옮기는 과정이 반복되며 대용량 데이터는 처리 불가능하다.

**근거:**
- "매번 이렇게 들어와서 이렇게 긴 수식을 작성하려고 하니 매번 파일 들어가서 범위 선택해서 이 수식을 입력해주기까지 굉장히 번거로울 겁니다." (유튜브, 2026-09-28)
- "이렇게 되면 우리가 피벗테이블로 이 전체 날짜에 대해서 한꺼번에 집계를 할 수가 없어요." (유튜브, 2026-09-28)
- "엑셀 파일을 열고 데이터 일부를 복사해서 채 GPT에 붙여 놓고 답변을 다시 엑셀로 옮깁니다. 매크로나 자동화 작업을 하려면 생각보다 손이 더 많이 갑니다." (유튜브, 2026-09-23)

## 2. 타깃 고객

**가장 먼저 쓸 사람:** 비개발 직장인, 1인 기업 사장, 마케터 — 엑셀을 매일 쓰지만 코딩을 모르는 사람들.

**지금 쓰는 대안과 한계:**
- 수동 복사붙여넣기 → 시간 낭비, 실수 다수
- VLOOKUP/수식 작성 → 복잡한 구조에서 막힘
- VBA/매크로 → 개발 지식 필요, 비개발자 진입 불가
- ChatGPT 복붙 → 대용량 처리 불가, 반복 작업
- 외부 엑셀 강의 수강 → 시간 소요, 실전 적용 어려움
- Power Query → 학습 곡선 높음, 비개발자 진입 장벽

## 3. 해법 한 줄

엑셀 파일을 업로드하면 자동으로 구조를 인식하고, 버튼 하나로 가로형→세로형 변환·중복 제거·시트 병합·데이터 정제를 수행하는 웹 도구.

## 4. 핵심 기능 (최대 3개)

### 기능 1: 스마트 구조 인식
- **사용자가 하는 일:** 엑셀 파일(.xlsx, .csv)을 업로드
- **화면이 보여주는 것:** 시트 목록, 각 시트의 컬럼명, 데이터 미리보기 (최대 100행), 감지된 데이터 타입(숫자/텍스트/날짜)
- **완료 기준:** 업로드 후 3초 안에 구조 인식 완료, 사용자가 시트 선택 가능

### 기능 2: 원클릭 변환
- **사용자가 하는 일:** 변환 유형 선택 (가로형→세로형, 중복 제거, 시트 병합, 데이터 정제)
- **화면이 보여주는 것:** 변환 전/후 미리보기, 변환 로그(어떤 작업이 수행되었는지), 다운로드 버튼
- **완료 기준:** 변환 후 미리보기 정확, 원본 데이터 손실 없음, 다운로드 정상 작동

### 기능 3: 저장된 변환 프리셋
- **사용자가 하는 일:** 자주 쓰는 변환 조합을 프리셋으로 저장
- **화면이 보여주는 것:** 프리셋 목록, "이 파일에 이 프리셋 적용" 버튼
- **완료 기준:** 프리셋 저장/적용 정상 작동, 재사용 시 원클릭 완료

## 5. 만들지 않는 것

- 실시간 협업 (多人 동시 편집)
- 엑셀 애드인 (Excel Add-in) 형태 — 웹으로 시작
- 대용량 데이터(10만 건 이상) 처리 — MVP는 1만 건 이하로 제한
- 자연어 기반 변환 지시 (AI 자동 생성) — 프리셋 기반으로 시작
- 모바일 앱
- 결제 시스템 실연동 — 결제 버튼만 배치, 실제 결제는 승인 후 연동

## 6. 화면 흐름

1. **첫 화면:** 랜딩 페이지 — "엑셀 파일을 드래그하세요" + 무료 체험 버튼
2. **업로드:** 파일 드래그 → 구조 인식 → 시트/컬럼 선택
3. **변환 선택:** 변환 유형 선택 (가로형→세로형, 중복 제거, 시트 병합, 데이터 정제)
4. **미리보기:** 변환 전/후 비교 → 다운로드 또는 재변환
5. **결제 유도:** 무료 3회 체험 후 "무제한 사용 — 월 9,900원" 버튼

## 7. 가격 가설

- **무료:** 3회 변환 (체험)
- **유료:** 월 9,900원 (무제한 변환, 프리셋 저장)
- **이유:** 엑셀 자동화 도구 시장에서 ElyxAI(€29/월), SheetXAI($20/월) 대비 저렴. 국내 직장인 기준 커피 2~3잔 값. 시간 절약 효과(월 10시간 절약 시 시급 1만 원 기준 월 10만 원 가치) 대비 합리적.
- **결제는 연동 지점만:** 실결제 금지. 승인 후 Stripe/토스페이먼츠 연동.

## 8. 성공 지표

**출시 2주 안에 확인할 숫자:** 방문자 중 결제 버튼 클릭률 (목표: 5% 이상)

## 9. 기술 메모

**기본 스택:** Next.js + TypeScript + Tailwind CSS

**추가 필요:**
- 엑셀 파일 파싱·변환·내보내기: `xlsx` (SheetJS) — 무료, 오픈소스. **모든 처리는 브라우저 안에서만** 한다.
- ~~파일 업로드: AWS S3 또는 Cloudflare R2~~ → **사용하지 않는다.** 아래 법적 리스크의 "로컬 처리 필수"와 충돌하므로 파일을 서버로 보내거나 저장하지 않는다. (2026-10-02 정정: 기술 메모와 법적 리스크 간 모순 해소)
- 상태 관리: Zustand (경량). 프리셋은 브라우저 `localStorage`에 저장한다 (서버 DB 없음).
- 배포: 서버가 필요 없는 정적 사이트(Next.js `output: 'export'`) → GitHub Pages 또는 Cloudflare 무료 배포.
- 화면에 "파일은 내 컴퓨터 밖으로 나가지 않습니다" 문구를 명확히 표시한다 (보안 우려가 핵심 구매 장벽이므로 차별점으로 활용).

**법적 리스크:**
- **개인정보보호법:** 클라우드 서버에서 엑셀 파일 처리 시 개인정보처리자 의무 발생. 2026-09-11 시행 개정안에 따라 유출 통지 의무 확대, 과징금 상한 매출 10%. → **로컬 처리 옵션 필수** (브라우저 내 처리, 서버 저장 없음)
- **전자상거래법:** 유료 서비스 판매 시 통신판매업 신고 의무. 표시·광고에 상호·대표자명·주소·전화·이메일·사업자등록번호 표시 필요.
- **AI기본법:** LLM 기능 추가 시 AI이용사업자 해당 가능. MVP 단계에서는 해당 없음 (프리셋 기반).
- **클라우드컴퓨팅법:** SaaS 제공 시 클라우드컴퓨팅서비스 제공자 해당 가능. → 실제 서비스 제공 전 변호사 검토 필요.

**결제 연동:** 승인 후 Stripe 또는 토스페이먼츠 연동. 실결제 금지.

## 11. 해법 3안 요약

### 안 1: 웹 기반 엑셀 변환기 (선택)
- 업로드 → 자동 구조 인식 → 변환 미리보기 → 다운로드
- **2주 안 1인+AI 제작 가능:** 가능 (Next.js + SheetJS)
- **장점:** 설치 불필요, 어디서나 사용, 결제 유도 쉬움
- **단점:** 대용량 처리 제한, 보안 우려

### 안 2: 엑셀 애드인 (Excel Add-in)
- 엑셀 안에서 직접 사용, 버튼 하나로 변환
- **2주 안 1인+AI 제작 가능:** 어려움 (Office.js API 학습 필요)
- **장점:** 워크플로우 변경 없음, 익숙한 환경
- **단점:** 개발 복잡도 높음, 배포 어려움

### 안 3: AI 기반 자동 변환 서비스
- 자연어로 지시 → AI가 변환 로직 생성 → 실행 → 결과 반환
- **2주 안 1인+AI 제작 가능:** 가능 (LLM API 활용)
- **장점:** 직관적, 유연함
- **단점:** AI 의존도 높음, 정확성 검증 필요, 비용 발생

**선택 이유:** 안 1이 가장 작게 만들어 가장 빨리 돈을 받아볼 수 있음. 2주 안 1인+AI 제작 가능, 설치 없이 바로 사용 가능, 결제 유도 쉬움.

## 12. Grill-Me 공격 결과

### 공격 1: "이미 무료 대안이 있지 않나?"
- **답:** Power Query, 엑셀 기본 기능, ChatGPT 무료 플랜이 있음. 하지만 학습 곡선 높고, 비개발자가 사용 어려움. 우리의 차별점은 "버튼 하나" 사용성과 국내 직장인 맞춤.
- **약점:** 무료 대안 대비 명확한 가치 증명 필요. → 무료 체험 3회로 체감 유도.

### 공격 2: "누가 정말 돈을 내나?"
- **답:** 유료 강의 구매 사례, AI 도구 구매 의사 있음. 하지만 명확한 WTP 근거 부족.
- **약점:** 실제 결제 의사 데이터 없음. → 출시 후 결제 버튼 클릭률로 검증.

### 공격 3: "보안 문제는?"
- **답:** 클라우드 처리 시 개인정보 유출 우려. 기업 데이터 업로기 꺼림.
- **약점:** 로컬 처리 옵션 필요. → MVP에서 브라우저 내 처리(서버 저장 없음) 구현.

### 공격 4: "대용량 처리는?"
- **답:** 웹 기반이므로 제한적. 10만 건 이상 처리 불가.
- **약점:** 대용량 데이터 사용자 이탈 가능. → MVP는 1만 건 이하로 제한, 대용량은 향후 과금.

### 남은 약점
- 실제 결제 의사 데이터 없음 (출시 후 검증 필요)
- 대용량 처리 불가 (MVP 범위 제한)
- 경쟁사 대비 명확한 기술적 차별점 없음 (사용성으로 승부)

## 13. 리스크

1. **치명적:** 개인정보 유출 사고 → 로컬 처리 옵션 필수, 보안 인증 획득
2. **높음:** 경쟁사 시장 점유율 → 사용성·가격 차별화
3. **중간:** 실제 결제 의사 부족 → 무료 체험 후 전환 전략
4. **낮음:** 기술적 난이도 → SheetJS 라이브러리 성숙
