## 3. 부서별 역할 상세

### 3.1. 총괄 기획·지휘 본부 (Hermes Master Agent)

**역할:** 대표님의 비서이자 총괄 기획자. 전체 파이프라인을 조율하고 각 부서의 업무를 지시·검수합니다.

**주요 업무:**
- 대표님의 지시를 받아 맞는 부서 스킬로 일을 나눔
- 불편 찾기·영상/레딧 분석 → `10jo-pain-mining`
- 아이템 → 해법·명세 → `10jo-product-spec`
- 명세 → 코딩(Claude Code) → `10jo-build-mvp`
- 배포·결제 → `10jo-deploy`
- "진행 상황 보고해" → `10jo-status-report`
- 큰 조사나 반복 작업은 하위 에이전트(delegate)에게 맡기고 결과를 검수해서 보고
- **승인 게이트를 지킴:** 아이템 확정, 개발 착수, 외부 배포, 돈 드는 일, 결제 연동은 대표 승인 전에 진행하지 않음

**도구:** Hermes Agent, Telegram, Google Drive

---

### 3.2. 불편 발굴·리서치팀 (Data Agent)

**역할:** 유튜브 자막·레딧·커뮤니티에서 돈 낼 만한 불편을 수집해 painpoints.json에 누적합니다.

**주요 업무:**
- 유튜브 영상 자막 다운로드 및 분석 (yt-dlp)
- 레딧, 네이버 카페, 디스코드 등 커뮤니티 고통 데이터 수집
- 불편 30선 및 지불용의(Willingness to Pay) 분석
- 고통 강도(Pain Intensity) 점수화
- 경쟁사 및 시장 트렌드 모니터링

**도구:** yt-dlp, BeautifulSoup, web_search, web_extract, Python

**산출물:**
- `01_pain_mining/painpoints.json` — 불편 데이터베이스
- `01_pain_mining/reports/` — 분석 리포트

---

### 3.3. 기획팀 (Spec Agent)

**역할:** 승인된 불편(P-번호)을 해법으로 바꾸고 개발팀이 바로 만들 수 있는 spec.md를 작성합니다.

**주요 업무:**
- 불편 데이터를 기반으로 해법 도출
- 제품 요구사항 문서(PRD) 작성
- 기능 정의서 및 기술 스택 명세
- 타깃 페르소나 정의
- 수익 모델 및 가격 전략 수립

**도구:** Claude Code (문서 생성), Notion/Google Sheets API

**산출물:**
- `02_product_spec/spec.md` — 제품 명세서
- `02_product_spec/business_plan.md` — 사업 기획서
- `02_product_spec/prd/` — PRD 문서

---

### 3.4. 소프트웨어 개발팀 (Claude Code)

**역할:** 승인된 spec.md를 Claude Code(claude -p)에 넘겨 03_apps_dev/ 폴더에 코드를 생성합니다.

**주요 업무:**
- 프론트엔드/백엔드 코딩
- 기능 구현 및 버그 수정
- 자동 테스트 및 배포 준비
- 노코드/로우코드 도구 활용

**도구:** Claude Code CLI, Node.js, Python, React/Vue, Streamlit/Dash

**산출물:**
- `03_apps_dev/app1/` — 마이크로 SaaS 소스코드
- `03_apps_dev/app2/` — 추가 제품 소스코드

---

### 3.5. 배포 & 운영팀 (DevOps Agent)

**역할:** 승인된 MVP를 무료 경로(임시 데모 URL, GitHub Pages)로 배포하고 결제 연동을 준비합니다.

**주요 업무:**
- GitHub에 코드 푸시
- Vercel/Netlify에 서버리스 배포
- 도메인 설정 및 SSL 인증서 발급
- 결제 시스템 연동 (Stripe, 토스페이먼츠)
- 고객 피드백 수집 및 분석

**도구:** Vercel, Netlify, GitHub, Stripe, 토스페이먼츠

**산출물:**
- `04_deployment/` — 배포 설정 및 스크립트
- `04_deployment/domain/` — 도메인 설정
- `04_deployment/payment/` — 결제 연동 설정

---

### 3.6. 경영 보고팀 (Report Agent)

**역할:** 불편·기획·개발·배포 전체 현황을 집계해 보고합니다.

**주요 업무:**
- 주간/월간 진행 상황 보고
- 매출 및 고객 피드백 분석
- 리스크 모니터링 및 대응 제안
- 투자 유치 자료 준비

**도구:** Google Sheets, Notion, Telegram

**산출물:**
- `05_reports/weekly/` — 주간 보고서
- `05_reports/monthly/` — 월간 보고서
- `05_reports/financial/` — 재무 보고서

## 5. 승인 게이트 (Approval Gate)

다음 작업은 **대표님 승인 없이 진행하지 않습니다:**

| 작업 | 승인 필요 | 담당 |
|---|---|---|
| 아이템 확정 | ✅ | 대표님 |
| 개발 착수 | ✅ | 대표님 |
| 외부 공개 배포 | ✅ | 대표님 |
| 돈이 드는 일 | ✅ | 대표님 |
| 결제 연동 | ✅ | 대표님 |
| 불편 데이터 수집 | ❌ | 불편 발굴팀 |
| 문서 작성 | ❌ | 기획팀 |
| 코드 개발 | ❌ | 개발팀 |
| 로컬 테스트 | ❌ | 개발팀 |
