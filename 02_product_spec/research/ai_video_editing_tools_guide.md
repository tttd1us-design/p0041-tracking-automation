## 1. 추천 도구 TOP 3 (무료 플랜)

### 1.1 CapCut (캡컷) — 숏폼 편집 기본값

- **가격:** 무료 (Standard $9.99/월, Pro $19.99/월)
- **플랫폼:** Windows, macOS, iOS, Android, Web
- **무료 플랜 기능:**
  - 1080p 내보내기 (워터마크 없음, Pro 템플릿 제외)
  - 멀티트랙 타임라인, 키프레임 애니메이션, 크로마키
  - 자동 자막 (영상당 10분)
  - AI 자동 편집 5회/월, AI 배경 제거 5회/월
  - 무료 음악 및 효과음 라이브러리
- **장점:** 숏폼 최적화, 한국어 지원, 직관적 UX, 워터마크 없음
- **단점:** Pro 템플릿 사용 시 워터마크, 4K 내보내기 유료, 클라우드 동기화 유료
- **출처:** https://www.gamsgo.com/ko/blog/%EC%BA%A1%EC%BB%B7-%ED%94%84%EB%A1%9C-%EB%AC%B4%EB%A3%8C, https://pexo.ai/blog/capcut-free-vs-paid-5843

### 1.2 Vrew (브루) — 한국어 자막 자동 생성 강자

- **가격:** 무료 (Light 월 6,600원, Standard 월 15,000원, Business 월 45,000원)
- **플랫폼:** Windows, macOS
- **무료 플랜 기능:**
  - 음성 인식 월 120분 (한국어 97% 정확도, 15분 영상 28초 처리)
  - AI 음성 월 1만 자
  - 텍스트로 영상 생성 3천 자
  - 1080p 내보내기 (워터마크 있음, 삭제는 Light 이상)
- **장점:** 한국어 음성 인식 정확도 높음, UI 완전 한국어 지원, 자막 기반 편집 (글자 지우면 영상도 잘림)
- **단점:** 워터마크 삭제 유료, 4K 내보내기 유료, 모바일 앱 2026년 7월 종료
- **출처:** https://www.moket.kr/tools/vrew, https://www.flowpixai.com/ko/ai-tools/vrew-ai-dubbing-analysis-2026.html

### 1.3 OpusClip — 롱폼 → 쇼츠 자동 클립 생성

- **가격:** 무료 (월 60분 처리), 유료 $19~$79/월
- **플랫폼:** Web
- **무료 플랜 기능:**
  - 월 60분 영상 처리
  - AI 하이라이트 클립 자동 추출
  - 바이럴 점수 매기기
  - 자동 자막, 9:16 세로형 리프레임
- **장점:** 긴 영상(1~2시간)에서 30~90초 클립 자동 추출, 바이럴 점수로 성과 예측
- **단점:** 월 60분 제한, 워터마크 있음, 영어·글로벌 채널 특화
- **출처:** https://www.how-toai.com/blog/ai-long-video-to-shorts-auto-clip-tools-2026, https://reap.video/blog/best-ai-video-editor

## 3. 10조 스튜디오 권장 워크플로우

### 3.1 쇼츠 제작 (1분 이내)

1. **CapCut**에서 원본 영상 편집
2. **Vrew**에서 한국어 자막 자동 생성 (15분 영상 28초)
3. **CapCut**에서 자막 오버레이, 효과 추가
4. 1080p 워터마크 없이 내보내기

### 3.2 롱폼 → 쇼츠 재가공

1. **OpusClip**에 롱폼 영상 업로드
2. AI가 하이라이트 클립 자동 추출 (30~90초)
3. 바이럴 점수 확인, 상위 클립 선택
4. **CapCut**에서 추가 편집, 자막 스타일 조정
5. 각 플랫폼(유튜브 쇼츠, 틱톡, 인스타 릴스)에 맞춰 내보내기

### 3.3 브랜딩 일관성

- **CapCut**에서 브랜드 템플릿 저장 (로고, 색상, 폰트)
- **Vrew**에서 자막 스타일 저장 (글자 크기, 색상, 배경)
- 모든 영상에 동일한 브랜드 요소 적용
