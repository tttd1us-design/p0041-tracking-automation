# 05_reports — 경영 보고팀

## 역할
불편·기획·개발·배포 전체 현황을 집계해 보고한다.

## 폴더 구조

```
05_reports/
├── weekly/             # 주간 보고서
├── monthly/            # 월간 보고서
├── quarterly/          # 분기 보고서
├── financial/
│   ├── revenue/        # 매출 보고서
│   ├── expenses/       # 지출 보고서
│   └── forecast/       # 예측 보고서
└── archive/
    ├── 2026-Q3/        # 2026년 3분기 보관
    └── 2026-Q4/        # 2026년 4분기 보관
```

## 작업 절차

1. **데이터 수집:** 각 부서 폴더에서 진행 상황 수집
2. **집계:** 주간/월간/분기 보고서 작성
3. **재무:** 매출, 지출, 예측 보고서 작성
4. **보고:** 대표님에게 보고

## 스킬
`10jo-status-report` 스킬을 참고한다.
