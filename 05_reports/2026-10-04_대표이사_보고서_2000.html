IV. 문제와 해결

■ Merge10 12파일 수정분 커밋 미실행 — DEV_NOTES·UI·컴포넌트·라이브러리 12파일 수정 후 아직 git add/commit 하지 않음. 커밋 전이라 정적 export(out/) 갱신 안 됨. 19:08→20:00 지속.

**결제 모델 모순** — 월 9,900원 구독은 무계정·정적배포와 충돌. 구독 권한을 클라이언트 localStorage만으로는 강제 불가.
A안(기간권/단건 결제) 또는 B안(오프라인 라이선스 키) 선택 필요. 단건 결제 2,900원/24시간 · 평생 39,000원 가설값. 개발팀은 MVP 유지 후 모델 전환 권고.
**크몽·숨고 자동 수집 불가** — 로그인 필요로 수동 조사 진행 중.
수동 조사 지속. 크롤링 자동화는 별도 스크래퍼 개발 필요(대표 승인 사안).
**롱폼 브랜치 자산 부재** — 회사 규칙 7-5절에 따르면 5개 브랜치 중 4개(쇼츠·롱폼·뮤직·북스)는 실제 자산이 없음.
롱폼 콘텐츠 기획서 작성 완료(LC-2026-001). 불편 데이터 48개 기반 콘텐츠 전략·SEO 전략·수익 모델·90일 실행 로드맵 수립. 대표 승인 시 90일 내 콘텐츠 30개 발행, 월간 100만 페이지뷰 목표 달성 가능.
